## 维护约定

1. 新增规则默认使用最窄匹配：至少包含标题别名 + 一个上下文锚点，避免影响无关作品。
2. 只替换标题、并用 `{[tmdbid=...;type=tv]}` 绑定身份，季集交给解析器，减少对集数格式的耦合。
3. 季集不符合 TMDB 规划时用组合规则：`被替换词 => 替换词 && 前定位词 <> 后定位词 >> EP±N`。
4. 规则只增不删；确需删除时在提交信息中说明原因。
